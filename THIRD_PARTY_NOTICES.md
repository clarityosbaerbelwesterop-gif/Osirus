# Third-party notices

Osirus did not copy source files from the projects below. The interaction
patterns were reimplemented in this repository: a thread with a typing
indicator, a reasoning shimmer, a short chain of steps, a collapsible tool
row, and animated quota bars. Motion uses opacity and transform only.

Vercel AI Elements (`vercel/ai-elements`) is not used.

Anthropic (Claude Code, Work) and Grok Bot publish no open interface code
that this tree copies. No logos, colors, or product names from those products
are used.
