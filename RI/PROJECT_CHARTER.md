# PROJECT CHARTER — Reasoning Intelligence (RI)

## Mission

Investigate whether intelligence can be constructed from a simple starting state via a fundamental mechanism of relationship formation, revision, and consequence examination, rather than presupposing a pre-trained large model or conventional architecture.

## Scope Boundaries

- Exclusive to branch `ri/isolated-foundation`
- All artifacts under `RI/`
- No merges, no product code changes, no paid compute without approval
- Research only; no production claims

## Success Criteria for First Cycle

Existence of documented, falsifiable hypotheses and at least one executed experiment with real results, or clear technical blockage. H1 success is not required.

## Governance

- All changes documented in RESEARCH_LOG.md and DECISIONS.md
- Results machine-readable where possible
- Status labels: planned / implemented / executed / tested / supported / refuted / blocked / unclear
