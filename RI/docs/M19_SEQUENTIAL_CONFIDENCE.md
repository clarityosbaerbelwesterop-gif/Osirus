# M19 — Adaptive Sequential Confidence Bounds for Stopping, Abstention and Drift

## Scope

M19 adds E12 as an isolated, reproducible research gate. It compares the M18-style fixed 14-example accuracy threshold with sequential Bernoulli SPRT and a time-uniform empirical-Bernstein confidence procedure. It also tests a target-versus-anchor drift monitor. Existing M16–M18 code remains the locked baseline until this experiment justifies a controlled integration.

## Decision procedures

- Fixed M18 baseline: accept the statistical candidate when observed 14-example accuracy is at least 0.85. Under the low-evidence task only 10 available observations are used; no evidence is fabricated.
- SPRT: simple hypotheses H0:p=0.85 and H1:p=0.95; alpha=0.05, beta=0.10. It stops at a likelihood-ratio boundary or returns inconclusive at the sample cap. Its conventional error interpretation requires independent Bernoulli observations under the specified hypotheses; values between 0.85 and 0.95 are an indifference region.
- Empirical Bernstein: calculates a bounded-observation empirical-Bernstein radius at each time with delta_t = 6 alpha / (pi^2 t^2). A union bound over alpha-spending controls repeated looks under the stated independent bounded-observation assumptions. It is deliberately conservative.
- Drift monitor: compares target probes against a calibration-anchor stream. It distinguishes target-specific drift from common-mode shifts only if anchor semantics remain stable.

## Safety contract

The sequential decision is not a production promotion. The guarded adapter grants eligibility only after independent validation, adversarial checks, locked regression and rollback availability all pass. It never mutates productive SkillMemory. The existing M17 gate remains mandatory.

## Benchmark

E12 uses 30 seeds, six noise levels (0%, 5%, 10%, 20%, 30%, 40%), insufficient-evidence and unidentifiable cases, a stable high-quality candidate case, and stationary / abrupt drift / gradual drift / noise-surge / recovery sequences. Observed mismatch-rate estimates with Wilson intervals, identifiable-task evidence cost, seed-cluster confidence intervals, and a no-monitor drift ablation are generated by evaluate.py and uploaded by CI as an artifact.

## Limitations

This benchmark is synthetic. Evidence-size cost of the conservative confidence bound must be compared against its reduction in statistical false acceptance before it can replace M18 in production. See the result files after CI generates them.
