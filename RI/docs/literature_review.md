# Literature Review (summary)

Relevant fields examined as knowledge sources (not blueprints):

- **Causal learning / inference** (Pearl, Gopnik, developmental work): children and systems can learn causal structure from interventions. Relevant for H1 relationship revision. Open: scaling to open-ended domains, computational efficiency.
- **Predictive processing / free energy** (Friston et al.): brains as hierarchical prediction machines. Comparison point; RI does not adopt the full framework.
- **Active learning & curiosity:** selection of informative experiences. Not yet implemented in E1.
- **Reinforcement learning & world models:** model-based RL shares prediction + update. Difference sought: explicit relationship revision rather than gradient descent on a fixed architecture.
- **Symbolic / compositional reasoning:** useful for multi-step consequences. Future comparison.
- **Continual learning:** catastrophic forgetting vs retention. To be tested in later milestones.

**Limitation:** This review draws on established literature known to the author. Exhaustive retrieval of 2024–2026 papers was not performed in the current session. Original sources should be consulted for precision.
