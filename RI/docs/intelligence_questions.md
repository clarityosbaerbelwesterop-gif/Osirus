# Intelligence Questions

## 3.1 What is a thought?

**Problem:** Operational definition of a thought process independent of language output.

**Working definition for RI:** An internal transformation that examines alternative relationships or consequences of observed state changes, updates expectations, and influences subsequent prediction or action selection in a way distinguishable from pure storage or fixed rule application.

**Status:** Open. E1 implements only predictive updating, not multi-alternative examination.

## 3.2 How do relationships arise?

Distinguish temporal co-occurrence, statistical regularity, predictive utility, causal, abstract, and spurious correlation.

**Experiment in E1:** Hidden conjunctive rule (color AND size) vs noise attribute. Candidate tracks conditionals; did not reliably discover the interaction over base rates in held-out tests.

## 3.3 How does experience change intelligence?

Difference between stored observation, changed expectation, changed rule, acquired skill, transferable abstraction.

**E1 observation:** Updating counts changes prediction; however, transfer to held-out was not superior to simple baselines.
