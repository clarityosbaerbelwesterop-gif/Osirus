# SKILL: Claude Code — Deep Codebase Comprehension & Engineering

## Core Principles

1. **Read Before Write**: Trace every symbol across backend routes, database schemas, stores, and UI components before modifying behavior.
2. **Cohesive Integration**: When unifying feature branches and open PRs, reconcile database migration numbering, TypeScript interfaces, environment schemas, and test suites cleanly.
3. **Minimal Token & Compute Footprint**: Optimize model prompts, cache responses deterministically and semantically, deduplicate in-flight requests, and route tasks to the most cost-effective capable model tier.
4. **Honest Telemetry & Error Handling**: Surface clear, actionable states in the UI without leaking internal stack traces or secrets.
